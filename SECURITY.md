# Security policy

## Supported versions

Security fixes are applied to the latest commit on `main`. Projects created from this template own their PocketBase upgrades, migration review, backup verification, and production security posture.

## Reporting a vulnerability

Use GitHub's private **Report a vulnerability** flow in the repository Security tab. Do not include credentials, personal data, exploit details, backup archives, or production URLs in a public issue.

Include the affected revision, impact, reproduction steps, and any suggested mitigation. Please allow time to validate and coordinate a fix before public disclosure.
